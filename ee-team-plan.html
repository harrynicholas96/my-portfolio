THE PROBLEM

Making the customer do the hard work

Users struggled to compare bulk-order mobile business plans with competitors. They must request a callback, then wait for an agent to manually create a quote. This time-consuming process forces them to search for information instead of accessing it instantly, creating friction and lost opportunities.

THE SOLUTION

Build an instant quote

Users can now build and save instant quotes using an interactive tool. Once satisfied, they can request a callback where the sales agent picks up the quote to personalise and complete the order.

WINS AND LEARNS

Empowering customers with instant quotes

This proof-of-concept demonstrated the potential for self-service quotation tools in the B2B space. While comprehensive usage data wasn't available post-launch due to organisational changes, user testing validated the core improvements to the customer experience.

Save time

Customers no longer wait for callbacks to receive basic pricing information, reducing quote time from days to minutes.

Low commitment

Users can explore options and pricing without the pressure of speaking to a sales agent, lowering the barrier to entry.

Flexible and visual

Interactive tool lets customers experiment with different configurations and see real-time impact on pricing.
